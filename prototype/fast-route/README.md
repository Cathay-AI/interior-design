# 快速找風格原型（fast-route）

只做「快速找風格」這一條路線：五個畫面，從一句話到一個家。對應簡報「04 產品體驗・畫面故事板」。

| # | 畫面 | 做什麼 |
|---|------|--------|
| 1 | 說出想像 | 按住說話或打字，逐字稿可編輯 |
| 2 | 參考圖 | 六種風格的即時算圖可複選，也能放自己的圖（只在瀏覽器預覽） |
| 3 | 確認需求 | 列出聽懂的空間、風格、預算；缺坪數時標「請補充」，只問必要的 |
| 4 | 3D 提案 | 即時 3D 房間：拖曳旋轉、A／B／C 視角；每次修改存成新版本 |
| 5 | 預算與限制 | 預算區間與依據、四態限制（已檢查／衝突／待補資料／不適用）、解鎖更多方案 |

RWD：820px 以下單欄、主要按鈕貼底；以上 3D 與操作面板並排。簡報的手機故事板只是示意，這裡是照產品來排版。

## 3D：輕量、不耗資源

做法參考 Dali 專案的前端（Three.js 需求式渲染）：

- **需求式渲染**：沒有動畫迴圈。相機或方案改變才畫一格；靜止時 GPU 不工作（e2e 會驗證靜止時 frame 數不變）。
- **拖曳時降解析度**，停手 240ms 後恢復細節（`lib/render-scheduler.js`，有單元測試）。
- **陰影只算一次**：場景是靜態的，`shadowMap.autoUpdate = false`。
- **不下載模型與貼圖**：家具用基本幾何，木紋與布紋用小張 canvas 貼圖。
- **延後載入**：Three.js（gzip 約 180KB）只在需要算圖時才動態載入，第一個畫面不用付這個成本。
- **離開畫面就釋放**：幾何、材質、貼圖與 WebGL context 全部 dispose。
- 不支援 WebGL 的裝置改顯示示意圖。

## 結構

- `lib/`：純函式，不碰 DOM，各有單元測試。
  - `intake.js`：逐字稿 → 空間／坪數／預算／屋況；`inferStyle` 猜風格，猜不到回 `null`。
  - `estimate.js`：坪數 × 屋況單價 → 預算區間；沒有坪數回 `null`（顯示「暫無可靠估算」）。
  - `rules.js`：限制檢查，每項恰好落在四態之一。
  - `taste.js`：風格資料（看屋二選一的口味引擎目前未接到畫面）。
  - `render-scheduler.js`：需求式渲染排程。
  - `room3d.js`：Three.js 房間（延後載入）；`art.js`：WebGL 不可用時的示意圖。
- `vendor/`：Three.js r180 與三個 addon（MIT，見 `vendor/THREE-LICENSE`）。
- `app.js`：狀態、五個畫面的渲染、語音與檔案等瀏覽器 API。
