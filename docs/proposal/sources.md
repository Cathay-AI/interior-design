Original values and attribution are retained. The source PDF has a title but no visible numeric chart on page 9: the HTML uses the existing qualitative heading terms without invented data. Literal `[icon: ...]` placeholders are replaced with simple SVG icons. Chapter dividers and mobile layouts are adapted while preserving the story and hierarchy. This is a faithful reconstruction, not a claim of pixel-identical rendering or new independent market research.

The old raster assets are retained privately for comparison only; they are removed from the public presentation’s current rendering. The earlier independent eight-page deck remains explicitly labeled legacy.
