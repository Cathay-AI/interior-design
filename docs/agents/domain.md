# Domain glossary

| 詞彙 | 本專案定義 |
|---|---|
| Serving platform | 提供屋主／夥伴使用的 Web、專案、版本、產物與任務服務；不等同自行訓練模型 |
| Skill | Victor repo 中由 agent host 執行的需求、生成及交付流程 |
| Review package | Manifest 與其指向的 GLB、圖面、圖片、表格、下載與來源資訊 |
| Revision | 一份可追溯、不可被悄悄覆寫的方案版本 |
| Layout | 幫助看懂格局與配置的檢視；不自動等於完整施工平面圖 |
| 效果圖 | 外觀與風格證據，不能當成量測尺寸來源 |
| 材料預估 | 在限定材料／計量範圍內的數量與費用；不是全案工程報價 |
| RFI | 特定位置／工項待回答的問題，包含影響、角色、時點與關閉證據 |
| Held | 某工項的關鍵條件未解決，暫不可進入指定作業 |
| 施工發行 | 針對明確工項、版本與責任確認後的用途狀態，非自動檢查通過的同義詞 |
| TA | 第一批使用者是有實際空間規劃需求的屋主；內部試點為 Mika、Victor |
| MVP | 用最小流程驗證單一真實空間能否從需求走到可修改、可交接方案 |
