# Domain glossary v0.2

| 詞彙 | 本專案定義 |
|---|---|
| Serving platform | 屋主使用的跨裝置 Web 服務，不指定生成引擎 |
| Intake | 語音／文字＋參考圖片與簡短需求確認 |
| 3D 提案 | 空間視覺成果；互動模型或多角度展示由選型決定，如實標示能力 |
| 粗略報價 | 有範圍、假設、來源與排除項的預算區間，不是承攬報價 |
| Taiwan-aware | 有來源及適用條件的法規／消防／機電／物理空間考量，非全面專業核准 |
| Rule finding | 已檢查、衝突、待確認或不適用的單項判斷 |
| Freemium | 免費基本成果，進階功能付費；額度、組合與價格未定 |
| Customer case | 有真實專案與展示同意的案例；概念示意不能冒充 |
| Revision | 可追溯的需求／結果／估價版本 |
| MVP | 完成簡單輸入、3D＋粗報價、理解限制與選擇升級的最小服務 |
