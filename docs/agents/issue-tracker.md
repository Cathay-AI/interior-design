# Issue tracker

- Repository：https://github.com/Cathay-AI/interior-design
- Project：https://github.com/orgs/Cathay-AI/projects/1
- 高層規劃：`docs/delivery/roadmap.md`；產品範圍：`docs/product/mvp.md`。
- GitHub Issues 為執行狀態來源；docs 保存願景、決策、範圍與初始化快照。
- 初始工作項目是 high-level 規劃與成果認領，不是已核准全部細節的 agent implementation ticket。
- 流程沿用現有 Status：Todo → In progress → Done。審查／阻礙透過標籤與原生 blocking 關係記錄；Done 需要列出成果與驗證證據。
- `planning` 表示待收斂；`needs-decision` 表示重大決策待定。未釐清的範圍不標 `ready-for-agent`。
- 姓名欄記錄建議推進主責，body 記錄協作者；未核對 GitHub username 不自動 assign。
- Milestones 表示成果門檻，不預填日期；時間由認領人估計後再設定。
- 父 issue 串起初始 proposal；子 issue 使用 native sub-issue 與 blocking links，body 也保留依賴文字以利閱讀。
- 使用者已授權本次初始化到 repo 與 Project。此授權不等於購買網域、付費雲端服務、傳訊第三人或發行施工圖。
