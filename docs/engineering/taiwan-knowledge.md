## 知識與判斷怎麼接起來？

```mermaid
flowchart LR
    A[地區・用途・尺寸・現況] --> B[挑選適用檢查]

    B --> E[幾何／規則計算]
```

法律要求、工程經驗值、廠商規格、使用者偏好分開標示。檢索到段落不是執行過檢查；沒有實測或完整幾何時不能推論通過。不能把一張生成圖片當成機電或消防配置的計算模型。

## 首批檢查的選擇原則

| 類別 | 可以評估的方向（非已支援清單） | 需要的輸入 |
|---|---|---|
| 物理空間 | 家具碰撞、門扇開啟、動線、維修空間 | 已知幾何與尺寸、產品操作範圍 |
| 消防 | 既有設備／避難相關設施是否受方案影響 | 用途、現況、配置與適用規範 |
| 機電 | 插座／設備／空調／給排水介面是否缺資料或衝突 | 既有點位、設備、路徑與專業條件 |
| 法規 | 需要查明的裝修／用途／地方條件 | 地區、建築用途、工程內容與版本 |

首版由 Even／Josh 與專業夥伴選定有限檢查集及測試案例。每項記錄 rule ID、類別、來源 URL／版本／查核日期、適用地區與用途、所需輸入、判斷方法、例外、結果及專業覆核狀態。資料缺漏或來源過期時標待確認，不悄悄套用全台單一數字。

這些是查核入口，不代表已完成特定案件的適用法規判定；地方、用途、版本與工項需另外確定。此輪文件不寫入未驗證的通用走道寬度、電力負載或消防距離數值。
