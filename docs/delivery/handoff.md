# 專業服務與施工：後續延伸

v0.2 的基本流程是語音／文字＋參考圖 → 3D＋粗略報價。專業交接、完整工程圖或統包施工不是基本體驗的前置步驟。

如後續付費產品包含專業深化，Even、Josh 協助釐清範圍與負責角色：

| 用途 | 需逐步補足 |
|---|---|
| 概念比較 | 需求、外觀、假設尺寸與預算區間 |
| 專業協調 | 實際尺寸、圖面與規格、設備介面、待決問題 |
| 正式詢價 | 工項、用量與費率依據、包含／排除與現況 |
| 施工／製作 | 現場、產品、必要詳圖與專業確認，按範圍發行 |

法規、消防或機電提示不是施工核准。支付進階費用也不自動完成專業審查。這些門檻由後續服務方案決定，不讓初次屋主必須先完成全套流程。
