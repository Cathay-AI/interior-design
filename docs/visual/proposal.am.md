## C 從想像到接手 {span=3 meta="JOURNEY"}
```flow LR
屋主想像 -> Skill 方案: 需求與尺寸
Skill 方案 -> *手機 3D: 模型與圖面
手機 3D -> 版本比較: 修改與保存
版本比較 -> 專業接手: 材料與問題
```
**尺寸有來源，產物有版本，未知事項看得見。**

## E 我們要驗證的差異 {meta="PRODUCT BET"}
```timeline v
Skill | 把生成能力變成服務
一致版本 | 模型、圖面、用量可追溯
專業接手 | 用真實回饋縮短落地距離
```
**商業假設：** 屋主工具入口，專業服務付費。
需求、價格與成本仍待驗證。

## F 用成果前進 {span=3 meta="MILESTONES"}
```timeline h
*M0 | 對齊需求 | 案例、交接與部署
M1 | 上線可看 | 輕量手機 3D
M2 | 可以修改 | 重產與版本比較
M3 | 可以交接 | 材料預估與問題
M4 | 真實試點 | 屋主與專業回饋
M5 | 施工探索 | 限定工項與責任
```
**第一個目標：兩位屋主完成修改，一位專業夥伴回饋。**
M5 依試點證據決定；不承諾全屋全自動施工圖。
