來源：2026-11-05 11:15–12:15 團隊會議紀錄，以及同日使用者追加指示。本文件是摘要；原紀錄末尾在「完整施工圖」處截斷，未補造缺失內容。

## 會議初步共識

短期以一般屋主為入口；從平面／需求走到互動 3D，先以牆地材、用量與材料預估驗證。AI 初期輔助並保留專業確認；借鑑 BIM 的資料一致性，不重建整套 BIM。中長期朝專業圖面、設計與施工交接前進。收費、角色投入與最終商業模式未定。

## 同日追加與範圍修正

使用者確認 serving platform、3D 展示、輕量 mobile render；要求先寫 proposal、願景、目標、MVP 與 high-level 分工，在 repo／Project 初始化後迭代。Victor 的 skill 成為現有生成起點；Mika、Victor 可作屋主，Even、Josh 有設計師／工班資源，Chris 有裝修經驗，全員可開發。Victor、Even、Chris 共同研究部署、架構、網域。

因此 MVP 第一條路徑改成「先接現有 skill 產物 → 上線檢視 → 修改重產 → 專業交接」，不把從零打造生成引擎列為前提。從文字開始可做概念，但尺寸、計量及施工用途需要另外補證據。
