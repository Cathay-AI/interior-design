# 需求與假設 v0.2

## 最新使用者確認（2026-11-05）

- 手機方便使用，電腦也可以；render 要輕量。
- 主流程：語音或文字＋參考圖片 → 3D 圖與粗略報價。
- 進階解鎖付費，並規劃客戶案例。
- 主打考量台灣工程法規、消防、機電配置與物理空間。
- Victor skill 只是早期想像，不作產品範例、不綁定實作。
- 仍維持 compact、圖多字少、中英文 README；先 high level、再依證據收斂。

## 定位

**考量台灣裝修條件、手機優先且電腦可用的 AI 空間設計服務。** 免費基本成果讓屋主快速理解方向與預算，進階功能付費。首批 TA 是探索住宅裝修想法的屋主；Mika、Victor 可作內部試點，仍需外部需求驗證。

## 待驗證

| 假設 | 證據 |
|---|---|
| 語音＋參考圖比專業表單容易開始 | 觀察手機錄音、改逐字稿、選圖與首次完成率 |
| 3D＋粗報價有足夠價值 | 使用者能解釋方案、預算範圍及未確認事項 |
| 台灣工程限制能形成差異 | 以有尺寸基準與來源的案例，專業覆核已支援規則 |
| 進階解鎖有人付費 | 區分點擊升級、口頭意願、sandbox 與真實付款 |
| 案例能建立信任 | 真實與同意展示的內容，觀察是否幫助使用者開始 |
| 單案成本能支撐免費入口 | 記錄生成、轉錄、儲存與人工成本，再決定額度／價格 |
